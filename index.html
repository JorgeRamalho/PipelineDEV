O que este projeto faz

Você escreve Python no Cursor, o Git guarda o código e o Jenkins executa o fluxo sozinho. A aplicação é o release gate: ela só devolve SUCCESS quando os quatro sinais abaixo passam.

  1. O Jenkins obtém o código.
  2. Prepara um ambiente Python isolado e instala as dependências.
  3. Roda os testes com Pytest.
  4. Constrói a imagem Docker e executa o container.
  5. Registra SUCCESS ou FAILURE.

Como abrir esta tela

Na pasta do projeto, no PowerShell:

docker compose up --build -d

Depois abra http://127.0.0.1:8000.

Sem Docker: python -m app.main serve

Pipeline Jenkins, etapa por etapa

O arquivo Jenkinsfile é a receita. O Jenkins só lê isso e executa. O parâmetro RELEASE_MODE decide o final: success deixa o container passar; failure manda TESTS_PASSED=false e o gate devolve FAILURE.

CheckoutPuxa o Git e lista os arquivos. Sem código, o resto nem começa.
Instalar dependênciasCria .venv e instala o Pytest. Sinal: DEPENDENCIES_INSTALLED.
Testes Python / PytestSe um teste falhar, o pipeline para aqui. Sinal: TESTS_PASSED.
Build DockerConstrói python-devops-pipeline:BUILD_NUMBER. Sinal: IMAGE_BUILT.
Executar containerRoda a app. Código 0 = SUCCESS, código 1 = FAILURE. Sinal: CONTAINER_RUNNING.
postArquiva reports/ e imprime RESULTADO DO PIPELINE: SUCCESS ou FAILURE.
